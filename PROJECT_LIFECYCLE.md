## 1. دورة حياة الطالب

```
                    ┌─────────────────────┐
                    │   مرشّح للقبول      │
                    │  (المتقدم)          │
                    └──────────┬──────────┘
                               │  enroll_student()
                               ▼
                    ┌─────────────────────┐
                    │    طالب مسجّل       │
                    │   (op.student)      │◄──── ربط تلقائي بـ res.partner
                    └──────────┬──────────┘
                               │
              ┌────────────────┼────────────────────────┐
              ▼                ▼                         ▼
   ┌─────────────────┐ ┌─────────────────┐  ┌──────────────────────┐
   │  تسجيل المواد  │ │  الرسوم الدراسية│  │  إنشاء حساب مستخدم  │
   │(op.subject.reg) │ │(fees.details)   │  │  (Portal User)       │
   └─────────────────┘ └─────────────────┘  └──────────────────────┘
              │                │
              ▼                ▼
   ┌─────────────────┐ ┌─────────────────┐
   │ جدول الحصص     │ │  الامتحانات     │
   │(timetable)      │ │(exam.attendees) │
   └─────────────────┘ └─────────────────┘
              │                │
              └────────┬───────┘
                       ▼
            ┌─────────────────────┐
            │   حضور وغياب       │
            │ (attendance.line)   │
            └─────────────────────┘
```

### البيانات الأساسية للطالب (`op.student`)

| الحقل | النوع | الوصف |
|---|---|---|
| `first_name` / `last_name` | Char | الاسم (مقسّم لثلاثة أجزاء) |
| `gr_no` | Char | رقم التسجيل — فريد لكل طالب |
| `birth_date` | Date | تاريخ الميلاد (لا يقبل تاريخاً مستقبلياً) |
| `gender` | Selection | الجنس (ذكر / أنثى / آخر) |
| `partner_id` | Many2one | ربط بـ `res.partner` (جهة اتصال) |
| `user_id` | Many2one | ربط بـ `res.users` (حساب دخول) |
| `course_detail_ids` | One2many | تاريخ الدراسة (كل مقرر دُرِس) |
| `fees_detail_ids` | One2many | تاريخ الرسوم المدفوعة |

## 2. دورة حياة سجل القبول

> **`op.admission.register`** هو "دورة القبول" التي تُفتح كل فصل أو سنة دراسية.

```
Draft ──► Confirmed ──► Application Gathering ──► Admission Process ──► Done
  │                                                                       │
  └─────────────────────────────────────────────────────────────────────►│
                              Cancel (في أي وقت)
```

| الحالة | المعنى | الدالة |
|---|---|---|
| `draft` | مسودة - قيد الإعداد | `set_to_draft()` |
| `confirm` | مؤكد - جاهز للاستقبال | `confirm_register()` |
| `application` | مرحلة جمع الطلبات | `start_application()` |
| `admission` | مرحلة قبول الطلبات | `start_admission()` |
| `done` | مغلق - انتهى القبول | `close_register()` |
| `cancel` | ملغى | `cancel_register()` |

**معطيات مهمة في سجل القبول:**
- تاريخ البداية والنهاية لقبول الطلبات
- الحد الأدنى والأقصى لعدد المقبولين
- الحد الأدنى للعمر (افتراضي: 3 سنوات)
- المقرر أو البرنامج المرتبط
- السنة الأكاديمية والفصل الدراسي

## 3. دورة حياة طلب القبول

> **`op.admission`** هو طلب الطالب الفردي داخل سجل القبول.

```
         ┌────────────────────────────────────────────┐
         │              Draft (مسودة)                 │
         └────────────────────┬───────────────────────┘
                              │ submit_form()
                              ▼
         ┌────────────────────────────────────────────┐
         │            Submitted (مُقدَّم)              │
         └────────────────────┬───────────────────────┘
                              │ confirm_in_progress()
                    ┌─────────┴──────────┐
                    ▼                    ▼
         ┌──────────────────┐  ┌─────────────────────┐
         │ Confirmed (مؤكد) │  │  Pending (معلّق)    │
         └────────┬─────────┘  └──────────┬──────────┘
                  │ admission_confirm()     │
                  ▼                        │
    ┌─────────────────────────┐            │
    │ Admission Confirm        │            │
    │ (قبول مبدئي)            │            │
    └────────────┬────────────┘            │
                 │ enroll_student()        │
                 ▼                         │
    ┌─────────────────────────┐            │
    │      Done (مكتمل)       │◄───────────┘
    │  ✅ الطالب مُسجَّل       │
    └─────────────────────────┘

    في أي مرحلة:
    ├── confirm_rejected()  →  Rejected  (مرفوض)
    └── confirm_cancel()   →  Cancelled (ملغى)
```

### ما يحدث عند `enroll_student()` تلقائياً:

```
enroll_student()
    │
    ├──► إنشاء سجل op.student (إذا لم يكن موجوداً)
    │       ├── نقل جميع البيانات الشخصية
    │       └── اختياري: إنشاء مستخدم Portal
    │
    ├──► إنشاء op.student.course
    │       ├── ربط بالمقرر والدفعة
    │       └── ربط بالسنة والفصل الأكاديمي
    │
    ├──► إنشاء op.student.fees.details
    │       └── توزيع الرسوم على الأقساط تلقائياً
    │
    └──► إنشاء op.subject.registration
            └── تحميل المواد الدراسية تلقائياً
```

## 4. دورة حياة الرسوم الدراسية

> **`op.student.fees.details`** يمثل كل قسط دراسي مرتبط بالطالب.

```
             Draft (مسودة)
                │
                │ get_invoice()
                ▼
     Invoice Created (فاتورة مُنشأة)
         │    ──────────────────────────► account.move (Odoo)
         │                                    │
         │                                    │ تسجيل الدفع
         │                                    ▼
         │                               Posted / Paid
         │
         └─► Cancel (ملغى)
```

**تدفق إنشاء الفاتورة:**

```
get_invoice()
    │
    ├── التحقق من وجود حساب إيرادات للمنتج
    ├── التحقق من أن المبلغ > صفر
    ├── حساب الخصم إن وجد: المبلغ × (1 - خصم%)
    ├── البحث عن عناصر الرسوم (op.fees.element)
    │     ├── إذا وُجدت: إنشاء سطر لكل عنصر
    │     └── إذا لم توجد: إنشاء سطر واحد بالمبلغ الكلي
    └── إنشاء account.move (فاتورة) وحفظ المعرّف
```

**أنواع جداول الرسوم (`op.fees.terms`):**

| النوع | الوصف |
|---|---|
| `fixed_days` | أقساط بعد عدد أيام محدد من تاريخ البدء |
| `fixed_date` | أقساط في تواريخ ثابتة محددة |

**قاعدة التحقق:** مجموع نسب الأقساط يجب أن يساوي 100% بالضبط.

## 5. دورة حياة الامتحان

> **`op.exam`** يمثل امتحاناً واحداً لمادة في جلسة امتحانات.

```
         ┌─────────────────────────────────┐
         │          Draft (مسودة)          │
         └─────────────┬───────────────────┘
                       │ act_schedule()
                       ▼
         ┌─────────────────────────────────┐
         │       Scheduled (مجدوَل)        │◄──────── يضاف حضور الطلاب هنا
         └─────────────┬───────────────────┘
                       │ act_held()
                       ▼
         ┌─────────────────────────────────┐
         │          Held (مُنعقد)          │◄──────── تُدخَل الدرجات هنا
         └─────────────┬───────────────────┘
                       │ act_result_updated()
                       ▼
         ┌─────────────────────────────────┐
         │    Result Updated (نتائج مُدخَلة)│
         └─────────────┬───────────────────┘
                       │ act_done()
                       ▼
         ┌─────────────────────────────────┐
         │           Done (مكتمل) ✅       │
         └─────────────────────────────────┘

    ┌────────────────────────────────────────┐
    │  يمكن الإلغاء من: Draft أو Scheduled  │
    │  act_cancel() → Cancel                 │
    │  ⚠️ يحذف جميع سجلات حضور الطلاب      │
    └────────────────────────────────────────┘
```

### التحققات التلقائية عند الحفظ:

| التحقق | الوصف |
|---|---|
| **التواريخ** | وقت الامتحان يجب أن يقع ضمن تواريخ جلسة الامتحانات |
| **الترتيب الزمني** | وقت البداية < وقت النهاية |
| **التداخل** | لا يمكن أن تتداخل امتحانات نفس المادة زمنياً |
| **الدرجات** | درجة النجاح ≤ الدرجة الكلية، وكلاهما > صفر |

### كشف الدرجات (`op.marksheet.register`):

```
Marksheet Register
    │
    ├── op.marksheet.line (درجة كل طالب في كل امتحان)
    │
    └── op.result.template (قالب النتائج بالتقديرات)
            └── op.grade.configuration (حدود كل تقدير: A, B, C...)
```

## 7. دورة حياة استعارة المكتبة

> **`op.media.movement`** يتتبع حركة كل نسخة من الكتاب/الوسيط.

```
         ┌─────────────────────────────┐
         │       Available (متاح)      │ ← حالة النسخة الأصلية
         └──────────────┬──────────────┘
                        │ issue_media()
              ┌─────────┴──────────┐
              ▼                    ▼
   ┌──────────────────┐  ┌──────────────────────┐
   │  Reserve (محجوز) │  │    Issue (مُعار)      │
   └──────────────────┘  └──────────┬───────────┘
                                    │ return_media()
                          ┌─────────┴──────────────┐
                          ▼                         ▼
               ┌─────────────────┐     ┌────────────────────────┐
               │ Return Done     │     │  Return (إرجاع بغرامة)  │
               │ (إرجاع نظيف) ✅│     │  ← يوجد تأخير           │
               └─────────────────┘     └────────────┬───────────┘
                                                    │ create_penalty_invoice()
                                                    ▼
                                       ┌────────────────────────┐
                                       │   account.move         │
                                       │   (فاتورة الغرامة)    │
                                       └────────────────────────┘

   في أي وقت:
   └── Lost (مفقود) ← إذا أُبلغ عن ضياع النسخة
```

**حساب الغرامة تلقائياً:**

```python
# calculate_penalty()
الأيام الفعلية = تاريخ الإرجاع الفعلي - تاريخ الإصدار
الأيام المسموحة = تاريخ الاستحقاق - تاريخ الإصدار
أيام التأخير = max(0, الأيام الفعلية - الأيام المسموحة)
الغرامة = أيام التأخير × الغرامة اليومية
```

## 📊 جدول الحالات الإجمالي

| الوحدة | النموذج | الحالات المتاحة |
|---|---|---|
| **القبول - السجل** | `op.admission.register` | `draft` → `confirm` → `application` → `admission` → `done` / `cancel` |
| **القبول - الطلب** | `op.admission` | `draft` → `submit` → `confirm` → `admission` → `done` / `reject` / `pending` / `cancel` |
| **الرسوم** | `op.student.fees.details` | `draft` → `invoice` / `cancel` |
| **الامتحان** | `op.exam` | `draft` → `schedule` → `held` → `result_updated` → `done` / `cancel` |
| **المكتبة** | `op.media.movement` | `available` → `reserve` / `issue` → `return` / `return_done` / `lost` |
| **دورة الطالب** | `op.student.course` | `running` → `finished` |

## 🔁 ملخص الدوال الرئيسية لكل دورة

| الدالة | الوحدة | الوصف |
|---|---|---|
| `submit_form()` | Admission | تقديم الطلب |
| `confirm_in_progress()` | Admission | تأكيد الطلب |
| `enroll_student()` | Admission | **تسجيل الطالب رسمياً + إنشاء الرسوم** |
| `get_invoice()` | Fees | إنشاء فاتورة الرسوم في Odoo |
| `act_schedule()` | Exam | جدولة الامتحان |
| `act_held()` | Exam | تسجيل انعقاد الامتحان |
| `act_result_updated()` | Exam | إدخال النتائج |
| `act_done()` | Exam | إغلاق الامتحان |
| `act_cancel()` | Exam | إلغاء + حذف الحضور |
| `get_attendance()` | Attendance | فتح ورقة الحضور للجلسة |
| `issue_media()` | Library | استعارة الكتاب |
| `return_media()` | Library | إرجاع الكتاب + حساب الغرامة |
| `create_penalty_invoice()` | Library | إنشاء فاتورة غرامة التأخير |
